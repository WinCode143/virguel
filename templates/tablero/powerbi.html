Dos formas de llevar los datos a Power BI.

Opción A — Conexión directa a PostgreSQL (recomendada)

  1. Power BI Desktop → Obtener datos → Base de datos PostgreSQL.
  2. Servidor: <host>:5434, base: virguel.
  3. Usuario de sólo lectura: powerbi_lector (se crea con manage.py crear_lector_powerbi).
  4. Elegir las vistas del esquema powerbi (ordenes, jornadas, stock_lotes, siniestros, egresos…). Ya traen nombres legibles.

Opción B — CSV por web

Power BI → Obtener datos → Web, con la URL del dataset y ?token=…{% if not hay_token %} Falta definir POWERBI_TOKEN en .env{% endif %}. También sirve para abrir en Excel.
